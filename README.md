# Tatvdhan Jaipur — The Wedding Chapter

An editorial couture website recreated from the supplied Tatvdhan reference PDF and exact brand assets. Built with Next.js, React, and Tailwind CSS through the Vinext runtime used by this project.

## Run locally

Requirements: Node.js 22.13 or newer.

    npm ci
    npm run dev

The development server prints its local URL in the terminal.

To create a production build:

    npm run build

## Page sections

- The Wedding Chapter hero
- Collection editorial and couture imagery
- News and collections
- Our Story
- The Man Himself
- Image gallery
- FAQ accordion
- Newsletter and footer

The supplied logo and couture photographs are under public/images. The logo remains the original PNG; photography is delivered as WebP to reduce page weight while retaining the supplied imagery.
